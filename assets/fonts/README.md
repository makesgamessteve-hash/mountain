# Fonts

## font8x8.png (128x64 RGBA)

ASCII 0–127 as a 16x8 grid of 8x8 glyphs. Glyph code `c` is at column
`c % 16`, row `c / 16`, with row 0 at the top, so its top-left pixel is at
`((c % 16) * 8, (c / 16) * 8)`.

- Glyph pixels are white `(255,255,255,255)`.
- Everything else is fully transparent `(0,0,0,0)`.
- Control codes (0–31) and 127 are blank.

The image is generated by `tools/gen_assets.py`, which parses
`tools/font8x8_basic.h`. In that header each glyph is 8 bytes, one per row, and
the least significant bit is the leftmost pixel.

`font8x8.png` is derived from **Daniel Hepper's public-domain font8x8**
(`font8x8_basic.h`). That font is based on Marcel Sondaar's and IBM's
public-domain VGA fonts.
